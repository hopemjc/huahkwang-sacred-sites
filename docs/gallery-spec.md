## 1. 設計共通原則

1. 沿用現有網站的版面、色彩、字型與 `assets/css/style.css` 設計；非經討論不任意更改。
2. 照片本體應完整顯示、不變形、不裁切；縮圖為便於辨識，可依既有縮圖框裁放。
3. 照片具有頁碼與文字說明；說明由 `assets/data/sacred-sites/bodhgaya.js` 提供。
4. 自動輪播預設間隔約 **6 秒**；切換照片的淡出效果約 **1.8 秒**。
5. 點選 Hero「照片導覽 ↓」可跳至照片主圖上方，並重新從第 1 張開始輪播。
6. 目前照片集使用的樣式與程式分別位於 `assets/css/style.css`、`assets/js/script.js`；網站不依賴 Astro 建置。

## 4. 自動輪播的可見性規則

1. 桌機版與手機版皆採「相簿主照片具有足夠可見面積，才啟動輪播」的判斷。
2. 相簿主圖離開可視範圍、瀏覽器分頁隱藏或開啟 Lightbox 時，應停止自動輪播。
3. 再次回到可視範圍時，保留目前照片，由新的六秒計時週期繼續。
4. 目前的可見性判斷是以相簿主圖與視窗的垂直重疊高度為準，門檻約為 `min(120px, 視窗高度 × 20%)`；不代表已建立視線追蹤或使用者閱讀意圖判斷。
5. 後續如更改相簿高度、加入新樣式或修改 Lightbox 行為，須複測此機制。

### 8.2 共用相簿架構

各聖地使用同一套 CSS 與 JavaScript：

- `assets/css/style.css`
- `assets/js/script.js`

各聖地獨立提供：

- HTML 頁面
- 完整照片（full）
- 縮圖（thumbs）
- 照片說明資料（JavaScript）

共用 JavaScript 依據以下 HTML 屬性取得設定：

- `data-gallery-count`：照片數量
- `data-gallery-path`：照片目錄
- `data-gallery-prefix`：聖地英文識別名稱

照片說明資料：

- `window.bodhgayaGallery`
- `window.kushinagarGallery`

JavaScript 透過 `window[prefix + 'Gallery']`
自動取得各聖地的照片說明。

Lightbox ID 採用 `{prefix}-lightbox` 命名。

相簿標題採用「聖地名稱＋現地影像」，
供 JavaScript 自動取得照片替代文字。

### 8.3 照片及縮圖規格

- 檔名採用聖地英文名稱加兩位數編號。
- 完整照片與縮圖檔名一致。
- 縮圖最長邊為 240 pixels。
- 縮圖維持原始長寬比例。
- 產生縮圖後須確認實際圖片尺寸，
  不得僅依完成張數判斷是否成功。

拘尸那羅共 12 張照片，
所有縮圖尺寸均已確認正確。

### 8.6 已知問題及待改善事項

#### Lightbox-01：底層網頁影像干擾

- 整體背景目前為 94% 不透明度。
- 開啟 Lightbox 後，底層相簿停止輪播。
- 切換放大照片時，底層原有影像仍隱約可見。
- 可評估採用完全不透明的背景。
- 尚未決定最終改善方案。

#### Lightbox-02：說明文字背景不一致

- 說明文字背景目前為 50% 不透明度。
- 不同長寬比的照片造成不同覆蓋效果。
- 文字方塊可能完全覆蓋照片、
  部分覆蓋照片，或完全位於留白區。
- 可評估漸層背景或照片與文字分離的版面。
- 需兼顧照片完整性、顯示尺寸及文字可讀性。

上述兩項問題暫不修改，
待文章展開／收合完成後再行討論。

原有手機縮圖智慧定位及首次載入速度等
待改善事項繼續保留。
