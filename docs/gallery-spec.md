## 1. 設計共通原則

1. 沿用現有網站的版面、色彩、字型與 `assets/css/style.css` 設計；非經討論不任意更改。
2. 照片本體應完整顯示、不變形、不裁切；縮圖為便於辨識，可依既有縮圖框裁放。
3. 照片具有頁碼與文字說明；說明由 `assets/data/sacred-sites/bodhgaya.js` 提供。
4. 自動輪播預設間隔約 **6 秒**；切換照片的淡出效果約 **1.8 秒**。
5. 點選 Hero「照片導覽 ↓」可跳至照片主圖上方，並重新從第 1 張開始輪播。
6. 目前照片集使用的樣式與程式分別位於 `assets/css/style.css`、`assets/js/script.js`；網站不依賴 Astro 建置。

## 4. 自動輪播的可見性規則

1. 桌機版與手機版皆採「相簿主照片具有足夠可見面積，才啟動輪播」的判斷。
2. 相簿主圖離開可視範圍、瀏覽器分頁隱藏或開啟 Lightbox 時，應停止自動輪播。
3. 再次回到可視範圍時，保留目前照片，由新的六秒計時週期繼續。
4. 目前的可見性判斷是以相簿主圖與視窗的垂直重疊高度為準，門檻約為 `min(120px, 視窗高度 × 20%)`；不代表已建立視線追蹤或使用者閱讀意圖判斷。
5. 後續如更改相簿高度、加入新樣式或修改 Lightbox 行為，須複測此機制。
